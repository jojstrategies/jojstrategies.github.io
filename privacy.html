Privacy Policy

Last updated: November 26, 2026

Jazz Channel Uploader is a private tool used only by its owner to upload, schedule and check videos on the owner's own YouTube channels.

Data accessed

With the owner's permission, the tool uses Google OAuth to access the YouTube Data API for the owner's channels: uploading videos and thumbnails, setting video metadata and publish times, managing playlists, and reading the status of those videos.

How data is used and stored

Access tokens are stored only on the owner's own computer and are used only to perform these actions. No data is sold, shared with third parties, or used for advertising. No data from other users is collected.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at https://myaccount.google.com/permissions.
